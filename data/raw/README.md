# Raw dataset

The project uses the Individual Household Electric Power Consumption
dataset from the UCI Machine Learning Repository.

Source:
https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption

## Setup

1. Download the dataset from the official source.
2. Extract `household_power_consumption.txt`.
3. Place the file in this directory.

Expected local path:

`data/raw/household_power_consumption.txt`

The raw dataset is intentionally excluded from Git to keep the
repository lightweight. This directory contains only documentation
in the public repository.
